About AchoDetect

AchoDetect is a voice detection project that analyzes uploaded audio to estimate whether a voice sounds human or AI-generated. It combines transparent forensic signal features with an easy web interface for investigation and learning.

Ethical Usage Framework

Use this system for investigation support only, with human review.

Technology

Forensic analysis includes spectral and temporal signal cues.
